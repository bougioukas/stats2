5.1 Introduction

The one-way repeated measures analysis of variance (also known as a within-subjects ANOVA) is an extension of the paired t-test designed to assess whether there are significant differences in the means of three or more related groups, such as comparing the difference between three or more time points.

Although, ANOVA can detect whether there are mean differences between the related groups, it does not identify which groups are different from the others. Therefore, after an ANOVA test concludes that at least one difference exists between the related groups (omnibus analysis), we should perform statistical tests that account for the number of comparisons (post hoc tests). Some of the most commonly used post hoc tests include the Tukey test, Bonferroni correction, and Holm test.

5.2 Research question and anova assumptions

A study investigated the effect of a drug on symptom intensity in a specific disease, assessing eight patients before (two pre-test baseline measures) and after treatment (three post-test measures). The primary question is whether the mean symptom intensity score changed over time.

5.2.1 Hypothesis testing for the one-way ANOVA test

NoteNull hypothesis and alternative hypothesis
  • \(H_0\): all related group means are equal (the means of symptom intensity score in the five time points are equal: \(\mu_{1} = \mu_{2} = \mu_{3} = \mu_{4} = \mu_{5}\))
  • \(H_1\): at least one group mean differs from the others (there is at least one group with mean symptom intensity score different from the others)

5.2.2 Assumptions

A. Normality: Scores are approximately normally distributed at each time point. To increase the number of observations used in assessing normality, we often examine the residuals from the ANOVA model for the entire dataset using a normal quantile plot of the standardized residuals (Normal Q-Q plot).

B. Sphericity: The variances of differences between all pairs of time points are equal (Mauchly’s test).

5.3 Import dataset and process the data variables

In this example, symptom intensity was evaluated on a twelve-point scale with higher values indicating more intense symptoms. Two pre-treatment baseline measurements were made, the first a month prior to treatment and the second one week prior to treatment. Post-treatments measures of symptom intensity were made after one week, one month, and one year following administration of the drug. In this simplified example, we have eight patients in the study.

Explanation

The data initially starts in a wide format, where each time point is stored in its own column (e.g., pre1, pre2, post1, post2, post3). The pivot_longer() function reshapes the data into a long format by stacking these columns into two new variables, with names that we specify (e.g., timepoint and score):

  • timepoint: Indicates when the measurement was taken.
  • score: Contains the corresponding symptom value.

Then, after reshaping to long format, we use mutate() to convert the subid and timepoint variables into factors (<fct>) by applying the factor() function within mutate().

5.5 Define the ANOVA model

First, we define the ANOVA model using the aov() function:

anova_model <- aov_car(score ~ timepoint + Error(subid/timepoint), data = dat_long)

It creates a model object that stores the mathematical association between time points and scores.

5.6 Check ANOVA Assumptions

5.6.1 Normality test and Q-Q plot

We can conduct a Shapiro-Wilk test to assess the normality of the standardized residuals from the ANOVA model:

# Get raw residuals
resids <- residuals(anova_model)

# Get standardized residuals
std_resids <- scale(resids)

# Run Shapiro-Wilk Test
shapiro.test(std_resids)

    Shapiro-Wilk normality test

data:  std_resids
W = 0.96412, p-value = 0.231

The Shapiro-Wilk test of normality suggests normal distributions (p=0.23 > 0.05; \(H_o\) is not rejected).


We can also examine the normality assumption using a normal quantile plot (Q-Q plot) of the standardized residuals:

# Q-Q plot
qqnorm(std_resids)
# add a reference line
qqline(std_resids, col = "red", lwd = 2)

The data points mostly fall along the diagonal line, indicating that the residuals are approximately normally distributed.


5.6.2 Sphericity assumption

This assumption is usually checked with the Mauchly’s sphericity test, where null hypothesis states that the variances of the differences are equal.

summary(anova_model)$sphericity.tests
          Test statistic  p-value
timepoint       0.036076 0.043094

In our example, the assumption of sphericity has not been met (p = 0.043). In this case, we have to correct the degrees of freedom in repeated ANOVA analysis.

There are two correction options \(\epsilon\) (epsilon) available: Greenhouse-Geisser (GG eps), or Huynh-Feldt (HF eps). The general recommendation is to use the Greenhouse-Geisser \(\epsilon\) correction when it is less than 0.75; otherwise, we should use the Huynh-Feldt \(\epsilon\) correction.

summary(anova_model)$pval.adjustments
             GG eps   Pr(>F[GG])    HF eps  Pr(>F[HF])
timepoint 0.4877324 0.0001340496 0.6737596 1.09767e-05
attr(,"na.action")
(Intercept) 
          1 
attr(,"class")
[1] "omit"

As the GG eps value is less than 0.75, we use the Greenhouse-Geisser adjustment of 0.488.

The corrected degrees of freedom are:

\(df_1*GG \ eps=4*0.488=1.95\)

and

\(df_2*HF \ eps=28*0.488=13.66\).

5.7 Perform ANOVA test (omnibus analysis)

We use jmv package to perform a Repeated Measures ANOVA because of its precise partitioning of variance. Unlike standard R outputs, anovaRM() function explicitly separates the total variance into two distinct tables: Within-Subjects Effects and Between-Subjects Effects.

results <- jmv::anovaRM(
1  data = dat,
  rm = list(
    list(
      label = "timepoint",
      levels = c("pre1", "pre2", "post1", "post2", "post3")
    )
  ),
  rmCells = list(
    list(measure = "pre1", cell = "pre1"),
    list(measure = "pre2", cell = "pre2"),
    list(measure = "post1", cell = "post1"),
    list(measure = "post2", cell = "post2"),
    list(measure = "post3", cell = "post3")
  ),
2  spherCorr = "GG"
)

5.8 Conduct Post hoc tests

To follow up on the significant main effect of time, pairwise comparisons were conducted using the Holm–Bonferroni adjustment. This procedure controls the family-wise error rate while being less conservative than the standard Bonferroni correction, thereby providing greater statistical power and reducing the likelihood of Type II errors.

post_hocs <- emmeans(anova_model, ~ timepoint)
pairs(post_hocs, adjust = "holm")

For example, the mean difference between prior1m and post1m is: 9.12 - 5.25 = 3.87, which is significant (adjusted p = 0.021).

 

Interpretation

Based on Greenhouse-Geisser correction for violation of sphericity, a one-way within-subjects ANOVA revealed a significant difference in the pre-test and post-test means, F(1.95, 13.66) = 18.62, p < 0.001. Pairwise comparisons using a Holm-Bonferroni correction to maintain an alpha level of 0.05 revealed that intensity of symptoms remained constant from the two pre-test baseline measures, significantly decreased after a week following drug therapy, and further significantly decreased after one month. Symptom intensity did not significantly differ from that level at the end of a year.
